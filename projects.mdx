## What is Project?

When using **Projects**, your employees can categorize their reported time in different projects. Using **Projects** is an effective way to categorize time and track how your resources are used.

## Create Projects

Click on **Settings - Time & time off - Add new - Project**. Give the Project a name and if needed, a scope. When using a **Scope**, only the employees within the scope will be able to report time for that specific project. You can scope projects to **Legal entity, Location** and **Department**. Read mot about reporting time [HERE](/report-and-approve-time).
