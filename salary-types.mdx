## What are salary types?

Does your organization pay employees **different kinds of reoccurring compensation**? Maybe some sort of supplemental wage? Salary types is then an excellent way to manage and differ the various types of compensation! The salary types will help you **see, analyse and transfer information** when needed.

## How to create salary types

To create salary types, navigate to **Settings** - **Compensation** and click **Add new** in the top right corner.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-28-2026-02-35-10-6599-PM.png?width=670&height=339&name=image-png-Jul-28-2026-02-35-10-6599-PM.png)

Select **Salary type**. Select a **name for the salary type** and press **Save** when done.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-28-2026-02-36-03-9214-PM.png?width=670&height=341&name=image-png-Jul-28-2026-02-36-03-9214-PM.png)

## How to manage salary types

If you want to **Edit** or **Delete** the salary type, click on the **three dots to the right** and make the changes needed. By choosing Edit you get the option to change the **Name,** **Calculate** **actual amount from employment scope**, **Allow yearly variable addition (%).** You can also add **Translations** to your salary type

## Calculate actual amount

By activating the option **Calculate actual amount from employment scope** on a salary type, the actual amount will be calculated automatically when you add a salary. The calculation is based on the employee’s employment scope (%) at the salary’s effective date.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-28-2026-02-36-58-5039-PM.png?width=670&height=339&name=image-png-Jul-28-2026-02-36-58-5039-PM.png)

## Allow yearly variable addition

When creating a salary type, you have the option to allow yearly variable addition for that specific salary type. This is done by toggling on **Allow yearly variable addition (%)**.

Click [**HERE**](/import-yearly-variable-addition) to read more about how to import yearly variable addition.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-28-2026-02-37-34-4911-PM.png?width=670&height=338&name=image-png-Jul-28-2026-02-37-34-4911-PM.png)

## Translate salary types

When creating an salary type, you have the option **to add translations**. The translations will vary depending on the language being used in the system, which is useful if you have employees using Hailey in different languages.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-28-2026-02-40-33-4036-PM.png?width=670&height=339&name=image-png-Jul-28-2026-02-40-33-4036-PM.png)

It is only the **Admin** within your organization that can manage and edit salary types.
