title: "Netvisor integration"

The integration with Netvisor enables you to synchronize employee, employment and salary data from Hailey.

## 1. What does the integration do?

Using the integration, data will be automatically transferred from Hailey to Netvisor. It's important to note that Hailey serves as the master in this context. This saves you time as you won't need to maintain both systems when there are changes to the data managed by the integration.

## 2. Before activating the integration

Whoever sets up the integration between Hailey and Netvisor needs to have access to an administrator account in both systems.

Before you activate the integration with Netvisor it is very important to make sure that all employees, whose data you wish to have sent to Netvisor, have all required fields filled out. If required fields are missing on the employee profile, this employee will not be included in the data transfer.

The required fields are:

- First name
- Last name
- Personal identity number
- Postal code
- Street address
- City
- Employment number
- Employment type
- Titles

**For employees with a personal identity number issued by other countries than Finland, the following fields are also required:**

- Date of Birth
- Gender

For Netvisor to know who the information, sent from Hailey, regards, the employment number in Hailey and the **Employee ID** in Netvisor need to match.

<Note>
  The integration doesn’t support **Employment numbers** that start with 0 or contain letters.
</Note>

Employees with an **Employment number** that is not registered in Netvisor will be created as a new employee in Netvisor. If the employment number in Hailey is missing, this employee will not be included in the integration.

### 2.1 Create custom field for Salary model

**To enable transfer of salary data, you need to create a custom employee field in Hailey with the type "Selection".** The content of this field will define the Salary model with which the employees Payroll will be handled in Netvisor. Read more about how to create a custom field [HERE](/custom-fields).

## 3. How does the integration work?

Every hour a sync between Hailey and Netvisor is done to ensure data is up to date in both systems. In this sync, we compare the data in Hailey to the data in Netvisor. If there are any inconsistencies found in the data, we will replace the data in Netvisor with the data registered in Hailey.

<Warning>
  **If there is data in Netvisor on the employees included in the integration that does not exist in Hailey, the integration will wipe this information since Hailey is the master.**

  However, if the field that is blank in Hailey is required in Netvisor, the information will not be wiped.
</Warning>

To be included in the integration, an employee needs to have all required fields filled out and have the employment status **In Service** or **Leaving** in Hailey. If you have scoped the integration in Hailey, the employee needs to match the scope in question.

## 4. Activate integration

To activate the integration to Netvisor, start by navigating to **API Resource Access** **rights.** Choose Finished integrations, and search for **Hailey HR.** After selecting the integration, make sure to change the status to "**Integration Allowed**"

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-26-2026-03-16-50-5880-PM.png?width=670&height=100&name=image-png-Jan-26-2026-03-16-50-5880-PM.png)

After you have activated the rights in Netvisor, you are ready to set up the integration in Hailey. To do this, navigate to **Settings - Integrations - Payroll** in Hailey.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Nov-07-2025-10-12-38-7454-AM.png?width=670&height=380&name=image-png-Nov-07-2025-10-12-38-7454-AM.png)

Click on **Netvisor**, and fill out **User ID, user key, Organisation ID & Sender.** Them click "**Authorize**".

- The **User ID and User key** are generated in Netvisor. You can do this by navigating to API identifiers and choosing **Create new API identifier**. You can find more detailed instructions from Netvisor [HERE](https://support.netvisor.fi/en/support/solutions/articles/77000498452-api-identifiers).
- The **organisation ID** is the Business ID of your organisation in Netvisor. You can find it in Netvisor by Navigating to **Company Basic Data and Settings - Basic data.**
- **Sender** is a free text field, so you can define your own value here.

Once authorized, you can choose to **Activate the integration**. Before activated, no data will be transferred between Hailey and Netvisor.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Nov-07-2025-10-10-44-5767-AM.png?width=670&height=458&name=image-png-Nov-07-2025-10-10-44-5767-AM.png)

When activating the integration, you need to choose a date from which to **transfer employments from.** All employments that are active after this date will be transferred when the sync is activated.

The integration splits the employment based on the **set transfer date**. If, for example, the field is set to January 1st 2021, a new employment will be created in Netvisor with the start date January 1st 2021. The existing employment will remain in Netvisor with its original start date, but an end date will be set to the day before the transfer date - so in this example, December 31 2020 (see image below).

![Skärmavbild 2026-05-22 kl. 14.08.13](https://docs.haileyhr.com/hs-fs/hubfs/Sk%C3%A4rmavbild%202026-05-22%20kl.%2014.08.13.png?width=670&height=152&name=Sk%C3%A4rmavbild%202026-05-22%20kl.%2014.08.13.png)

<Note>
  When transfering the employment data, we only update information from the current **Active employment** in Hailey. If you have historical employments in Hailey that do not match the data in Netvisor, this will not be updated.
</Note>

### 4.1. Activate salary sync

**If you want to transfer salary data from Hailey to Netvisor, activate "Sync salaries"**. You need to choose a date from when you want the salaries to be transferred from Hailey to Netvisor. All salaries that are active after this date will be transferred when the sync is activated. Note that Hailey is the master and will override any existing salary data in Netvisor on the included employees.

Under **"Salary custom field"**, choose the custom field you created to transfer the salary models of each employee to Netvisor.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Dec-09-2025-01-35-17-0117-PM.png?width=556&height=378&name=image-png-Dec-09-2025-01-35-17-0117-PM.png)

**Finally, to enable correct transfer of salary data, you need to map your salary types in Hailey to the correlating salary type in Netvisor.** You will see a list of your organisations salary types in Hailey, and need to fill out the corresponding **Salary type number** from Netvisor.

To find this information in Netvisor, navigate to **Salaries - Payroll - Salary model management**. Choose **Company-specific salary types** to view a list of all salary types.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Dec-09-2025-09-42-02-4496-AM.png?width=544&height=318&name=image-png-Dec-09-2025-09-42-02-4496-AM.png)

In Hailey, you need to fill out the **Salary type number**, which is found in the first column from the left:

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Dec-09-2025-09-43-31-1590-AM.png?width=613&height=155&name=image-png-Dec-09-2025-09-43-31-1590-AM.png)

### 4.2 Scope the integration

You can optionally choose to Scope the integration to include only parts of your organisation. You can scope the integration on **Legal entity** and/or **Location**. If these fields are left empty, all employees with the employment status **In Service** or **Leaving** (with all required fields filled out) will be included in the integration.

If you enter a Legal entity or Location in these fields, **only employees belonging to these groups  will be included in the integration.**

<Note>
  When End date for an employee is set in Hailey, the integration also populates the field "**Reason for ending**" in Netvisor. The value in this field is defaulted to "**Other**" as Hailey does not have a corresponding field. This value can then be changed in Netvisor.
</Note>

<Warning>
  The fields **Personal Identity Number, Date of Birth, Gender and Employment number** are **not updated** in Netvisor if changed in Hailey after they have originally been transferred between the systems. **The reason for this is that these fields are locked in Netvisor and cannot be edited.**
</Warning>

**When synchronizing with activated salary sync:**

We will transfer the active salary amounts from Hailey to Netvisor. Please note that we do not transfer **"Pay period"** from Hailey to Netvisor, as this is configured by **Salary Type** in Netvisor. Make sure to have different salary types for Hourly and Monthly salaries in Hailey, to ensure the correct amount is synced.

<Note>
  When transferring salaries to Netvisor, we will automatically populate the following fields:

  - **Advance debt account** will have value **1751 Saamiset työntekijöiltä**
  - **Payslip delivery method** will have value **Electronic payslip**

  You can then update the values in Netvisor. Hailey will not override these changes.
</Note>

## Troubleshooting

Is something not working as expected when you have finished setting up the integration? Here are some things you can check on your own!

### Some employees in the organisation are not transferring as expected

- **Do these employees have an employment number entered in Hailey?** If not, they will not be included in the transfer.
- **Does the employment number in Hailey include letters, or start with 0?** These employees will not be included in the transfer, as Netvisor does not support letters or 0 as the starting number for employment numbers.
- **Do these employees have an active employment in Hailey?** In the integration to Netvisor we only include employees with the statuses **In service** or **Leaving**. This means that if you have employees in Hailey that have not started their employment yet, they will be transferred on their start date.
- **Do these employees have parallel employments in Hailey?** These employees are not included in the integration, as Netvisor does not handle parallel employments.
- **Are all required fields filled out on these employees?** If an employee is missing any of the required fields, we will not transfer the employee in question.
- **Do these employees have a Finnish Personal Identity Number?** If not, the fields Date of Birth and Gender are also required. If yes, please double check that the Personal Identity Number is marked as Finnish on the profile.

### Some salaries on the included employees are not transferring as expected

- **Is this salary Active?** If the salary has not started yet, it will be transferred on the start date of the salary.
- **Have these salaries ended?** If they are not active from the "sync salaries from" date, they will not be included in the transfer.
- **Does this salary have a salary type registered in Hailey?** If not, it will not be included in the transfer. You can add the salary type by editing the salary information on the employee profile in Hailey.
- **The amount in Netvisor is different to the amount in Hailey.** Does the employee have multiple active salaries with the same salary type in Hailey? In this case we will summarize the salaries together in Netvisor.
