## What is a reference check?

**Reference Check** makes it easy and convenient to **collect references from candidates** during the recruitment process. To use Hailey's reference check, a recruitment process is needed. Read more about the recruitment in Hailey **[HERE](/start-and-manage-recruitment).**

In Hailey, **Reference Check** is a **digital flow** where you can **request, receive, and manage references** directly in the system. You get a clear overview of which references have been added, who has responded, and **all information is automatically saved** in the recruitment - all in one place.

Collected references are displayed **under Reference Check**, making it easy to **view and manage** each one.

## How do you request a reference?

The recruiter can **request references directly in Hailey**. A **message is automatically sent to the candidate**, who can easily **add references** with name, phone, email, and position (e.g., manager, colleague, or other).

To request a reference: click Request Reference - Write a message to the candidate - click **_Request Reference_**_._

<Note>
  If the candidate selects **Other**, they can specify their relationship with the reference.
</Note>

## Add a reference

Sometimes it’s easier to **add references manually** instead of requesting them from the candidate. This gives you full control and lets you quickly enter information directly into the system.

For each reference, fill in:

- **Name:** the full name of the reference
- **Email:** the reference’s email address
- **Phone:** the reference’s phone number
- **Relationship:** select the relationship (e.g., boss, colleague, other). If you select **Other**, you can provide more details.
- **Comment:** add any notes or information about the reference

You can add multiple references in the same step, keeping everything neatly organized under **Reference Check,** perfect for having all your information in one place.

## Request an assessment

Once the references are added, you can move on to the next step - **Request Assessment**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Oct-13-2025-01-47-26-3216-PM.png?width=670&height=461&name=image-png-Oct-13-2025-01-47-26-3216-PM.png)

Begin by selecting the language you’d like the email sent to your reference to be written in.

Then, add the questions you want to send to the reference. Your selected questions are **automatically saved as defaults** for future recruitments, **but you can always change, add, or remove questions as needed**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Oct-13-2025-01-53-07-5867-PM.png?width=670&height=463&name=image-png-Oct-13-2025-01-53-07-5867-PM.png)

When the questions are ready, **send an email request to the reference**. They will receive your questions and **can respond directly via email**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Oct-13-2025-01-57-06-2518-PM.png?width=670&height=572&name=image-png-Oct-13-2025-01-57-06-2518-PM.png)

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Oct-13-2025-01-58-49-6437-PM.png?width=670&height=643&name=image-png-Oct-13-2025-01-58-49-6437-PM.png)

If the reference prefers not to provide written assessment, they can:

- **Request to be contacted by phone**, or
- **Decline to provide an assessment**

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Oct-13-2025-01-59-53-5654-PM.png?width=670&height=572&name=image-png-Oct-13-2025-01-59-53-5654-PM.png)

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Oct-13-2025-02-05-38-5136-PM.png?width=670&height=462&name=image-png-Oct-13-2025-02-05-38-5136-PM.png)

Under the tab **Reference** **Check** you’ll find an overview of the references' responses. Here, you can see who has requested a phone call, if anyone has declined, and when an assessment has been submitted.

By **clicking on the references' name, you can read their full assessment.**

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Oct-13-2025-02-02-36-3053-PM.png?width=670&height=512&name=image-png-Oct-13-2025-02-02-36-3053-PM.png)

This flow lets you **customize communication for each recruitment** while **saving time** by **reusing** **your most common questions**.

## Add an assessment manually

In addition to sending an email request, you can **also add an assessment manually**. This is useful if **you’ve spoken to the reference by phone** or received information in another way.

Under **Add Assessment Manually**, you can **enter the assessment directly into the system**, keeping all reference information in one place.

This allows you to document conversations or supplementary information and ensures that **all references and assessments are saved in a structured** way under **Reference Check**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Oct-13-2025-02-06-29-5455-PM.png?width=670&height=361&name=image-png-Oct-13-2025-02-06-29-5455-PM.png)

## Common questions

**Question 1:** Do I need to create the same questions every time I request a reference assessment?

No, the questions are automatically saved within the same recruitment process. When you request a new assessment, previously created questions will still be available and can be reused or edited.

**Question 2:** Do all fields need to be added in order to [**add a reference manually**](/template-new-article-0-0#add_a_reference)?

To add a reference manually, the reference's **name** and **email address** need to be added.
