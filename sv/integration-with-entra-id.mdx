title: "Integration med Entra ID"
---

Vill du att nya medarbetare automatiskt ska skapas i Entra ID när de läggs till i Hailey? Med vår integration till Entra ID är detta möjligt – tillsammans med smidig överföring av data som befattningar och anställningsnummer!

<Tip>
  Första gången du aktiverar en av **Haileys standardintegrationer**? Börja med att läsa den [**HÄR**](/sv/haileys-standard-integrations) guiden för att veta vad du ska tänka på innan du sätter igång.
</Tip>

## Vad gör integrationen?

Vid varje synkronisering kommer inkluderad data[https://docs.haileyhr.com/sv/integration-med-kleer-0#vilken-data-ar-inkluderad](/sv/integration-with-kleer-salary-and-employee-data#vilken-data-ar-inkluderad)att **automatiskt** uppdateras via **API överföring** **till Entra ID** och få samma värde som finns i Hailey, eftersom **Hailey är master** (facit).

Sammanfattningsvis kan integrationen hjälpa er med följande saker:

- Skapa nya användare i Entra ID
- Uppdatera information om användare i Entra ID
- Inaktivera användare i Entra ID efter deras sista arbetsdag (_valfritt_)

## Hur fungerar integrationen?

Med API-överföringen sker en synkronisering mellan Hailey och Entra ID **varje timme** baserat på förändringar. Detta innebär att:

- Inkluderad data som inte överensstämmer mellan Hailey och Entra ID kommer att uppdateras med den information som finns i Hailey varje timme.

<Note>
  Haileys integration med Entra ID är anpassad för det molnbaserade Entra ID.
</Note>

## Vilken data är inkluderad i integrationen?

| **HAILEY** | **Entra ID** |
| --- | --- |
| Företagsmail | User principal name |
| Företagsmail (utan @domän) | Mail nickname (utan separering) |
| Jobbtelefon | Business phone |
| Förnamn | First name |
| Efternamn | Last name |
| Förnamn + Efternamn | Display name |

**Valbara datafält:**

| **HAILEY** | **Entra ID** |
| --- | --- |
| Titel | Job title (comma separated) |
| Avdelning | Department |
| Legal enhet | Company name |
| Kontor | Office location |
| Anställningsdatum | Employee hire date |
| Anställningsnummer | Employee ID |
| Rapporterar till | Manager |
| Telefonnummer privat, telefonnummer jobb eller eget fält | Mobile phone |

## Vad krävs för att ingå i integrationen?

För att en användare **ska ingå/skapas i integrationen** behöver medarbetaren ha:

- Företagsmail som matchar er domän

Medarbetare synkroniseras mellan Hailey och Entra ID genom att företagsmailen i Hailey matchas mot UPN i Entra ID. Om ingen matchande UPN finns, skapar Hailey automatiskt en ny användare i Entra ID.

Medarbetare med följande **anställningsstatus** ingår i integrationen:

- Ska börja
- I tjänst
- Ska lämna

## Gäller integrationen inte hela företaget?

Då finns det möjlighet att **omfatta** integrationen!

Om dessa fält lämnas tomma kommer alla anställda som uppfyller krav för integrationen att synkas över.

<Note>
  **Exempelbilden** nedan visar att endast medarbetare som tillhör den valda legala enheten och den valda arbetsplatsen som anges i integrationsuppsättningen, kommer att inkluderas i integrationen mot Entra ID.
</Note>

![](https://docs.haileyhr.com/hs-fs/hubfs/undefined-Jun-12-2026-07-23-35-4807-AM.png?width=670&height=284&name=undefined-Jun-12-2026-07-23-35-4807-AM.png)

### Det är även möjligt att skapa upp flera integrationer mot olika/flera konton i Entra ID.

- Om ert företag har flera arbetsplatser och/eller legala enheter i Hailey kan det vara fördelaktigt att skapa separata integrationer med Entra ID till olika/flera Entra ID konton.

Om ni **vill ha flera uppsättningar av integrationen mot olika Entra ID konton** gör ni om samma process som beskrivit ovan. Med andra ord, navigera till rubriken **Identitet och åtkomst** sedan gör ni på samma sätt som när ni satte upp den första integrationen.

![](https://docs.haileyhr.com/hs-fs/hubfs/undefined-Jun-12-2026-07-24-25-4414-AM.png?width=670&height=439&name=undefined-Jun-12-2026-07-24-25-4414-AM.png)

Hur gör en medarbetare vid första inloggning i Entra ID?

När en ny medarbetare, som skapats upp via integrationen, loggar in på sitt Entra ID-konto för första gången använder medarbetaren ange standardlösenord som angavs vid konfigureringen av Entra ID-integrationen i Hailey.

![](https://docs.haileyhr.com/hs-fs/hubfs/undefined-Jun-09-2026-01-05-15-8499-PM.png?width=670&height=559&name=undefined-Jun-09-2026-01-05-15-8499-PM.png)

När medarbetaren angett **standardlösenordet** och klickat på **Logga in,** kommer medarbetaren att uppmanas att skapa ett eget lösenord på nästa sida.

## Vanliga fragor

**Fråga 1:** Om jag gör en ändring i Entra ID, kommer det då ändras i Hailey?

Hailey är master vilken innebär att för den data som omfattas av integrationen är Hailey den primära datakällan. Om en ändring görs direkt i Entra ID på ett fält som ingår i integrationen kommer värdet vid nästa synkronisering att återställas till det värde som finns i Hailey.

**Fråga 2:** Hur kommer användare som redan finns i vårt Entra ID att matchas och hanteras när synkroniseringen aktiveras, skapas det dubbletter av användarna?

Integrationen identifierar medarbetare utifrån deras företagsmail. Om mejladressen redan finns i Entra ID kommer **inte** dubbletter att skapas ut utan integrationen identifierar och matchar till användarens redan uppsatta profil.

**Fråga 3**: Vad händer om jag ändrar en medarbetares företagsmail i Hailey, hur påverkar det integrationen?

När ni ändrar företagsmejladressen på en medarbetare i Hailey skapas en ny profil i Entra ID. Detta beror på att e-postadressen används som identifiering vid skapandet av medarbetarens konto och fungerar som kopplingen mellan systemen.

**Fråga 4:** Fungerar integrationen med lokalt Active Directory (on-premises)?

Haileys integration med Entra ID är anpassad för det molnbaserade Entra ID.
