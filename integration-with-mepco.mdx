title: "Integration with Mepco"
---

The integration with Mepco enables you to export employee data to create and update users in Mepco, aswell as import your time-off data from Mepco to Hailey to enable usage of Hailey's time-off analytics.

## 1. What does the integration do?

This integration consists of two parts:

- **Easily import time off data from Mepco to Hailey with a CSV-file**. This means that the time off changes made in Mepco can be updated by exporting a file from Mepco that you import into Hailey directly. In this way, the new data does not have to be entered into two different systems manually, which reduces the time spent on administrative work.
- **Seamlessly transfer employee data from Hailey to Mepco with a CSV-file**. This file can be used to both create new users in Mepco and make changes to existing users. The solutions ensures that you do not need to register employees manually in two different systems.

## 2. Before activating the integration

### 2.1. Time-off from Mepco to Hailey

- Ensure that the file is in the correct Mepco adjusted format before importing it into Hailey. **If you have any questions about the export file from Mepco, feel free to reach out to their support team for assistance.** <img src="https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-17-2024-12-28-08-1921-PM.png?width=461&height=145&name=image-png-Jul-17-2024-12-28-08-1921-PM.png" alt="" />
- You'll need to have matching time off reasons in Hailey and Mepco, in order for the import to work. **Make sure that the time off reasons are consistently named with matching lower and upper case letters for the integration to function smoothly.**
- Make sure that the **Personal ID** in Mepco corresponds to the **Employment number** in Hailey.

<Note>
  💡 To properly use the Time Off analytics for the imported time off - make sure that you've set up work hours for the employees. Read more about work hours [here](/time-and-time-off-settings#work-hours)
</Note>

<Warning>
  ❗️ The column titles in the file must match the titles shown in the picture exactly, including uppercase letters. Additionally, your time off reasons in Hailey should correspond to the Sick leave code entered in the file.
</Warning>

## 3. Activate integration

To activate the integration, go to Settings > Integrations in Hailey, go to the 'All' tab and pick Mepco. Set the integration to Active and then save the setting.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Mar-06-2025-09-37-05-2103-AM.png?width=461&height=262&name=image-png-Mar-06-2025-09-37-05-2103-AM.png)

## 4. How to use the integration

### 4.1. Time-off from Mepco to Hailey

After the integration is activated, you'll easily find the import option in your company's Time off view under Reports. You'll go to Reports, then head to Time Off. On the next view, you'll find the Import-button next to the date picker. Choose Mepco Time off.

![Skärmavbild 2024-06-14 kl- 10-34-32-png](https://docs.haileyhr.com/hs-fs/hubfs/Sk%C3%A4rmavbild%202024-06-14%20kl-%2010-34-32-png.png?width=389&height=103&name=Sk%C3%A4rmavbild%202024-06-14%20kl-%2010-34-32-png.png)

On the next view, select (or drag and drop) the Mepco time off file you'd like import and pick Import.

![Skärmavbild 2024-06-14 kl- 10-39-40-png](https://docs.haileyhr.com/hs-fs/hubfs/Sk%C3%A4rmavbild%202024-06-14%20kl-%2010-39-40-png.png?width=418&height=191&name=Sk%C3%A4rmavbild%202024-06-14%20kl-%2010-39-40-png.png)

After this step, the file import is done and you can view your employees imported time off from Mepco in Hailey!

### 4.2. Employee data from Hailey to Mepco

After the integration is activated, you can export the Mepco employee file by navigating to Reports - Mepco. When clicking on Export, you will get to select from which dates you want to include data in the file:

![Screenshot 2025-05-28 at 11.22.35](https://docs.haileyhr.com/hs-fs/hubfs/Screenshot%202025-05-28%20at%2011.22.35.png?width=670&height=140&name=Screenshot%202025-05-28%20at%2011.22.35.png)

<Warning>
  Before importing the file to Mepco - **check that the employment numbers of the included employees match the ones in Mepco,** to make sure the correct data is updated on the correct users.
</Warning>

<Note>
  The exported employee file will include all employees with an active employment during the selected time period.
</Note>
