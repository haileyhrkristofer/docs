---
title: "Manage yearly variable additions"
---

In this guide, we go through how to add and change yearly variable additions for an employee's salary.

## What is a yearly variable addition?

A yearly variable addition is a percentage-based addition to an employee's salary. It can be used for bonuses or other variable compensation and becomes active from the selected effective date.

<Note>
  The yearly variable addition is entered as a percentage of the salary and becomes active from the selected effective date.
</Note>

## Add a yearly variable addition

To add a yearly variable addition, open the employee's profile and navigate to the **Compensation** tab. Select the salary you want to update, then click **Actions - Add yearly variable addition**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Sep-24-2026-07-19-52-9122-AM.png?width=670&height=342&name=image-png-Sep-24-2026-07-19-52-9122-AM.png)

Enter the **effective date** and the **percentage of salary** that the yearly variable addition should be based on, then click **Save**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Sep-24-2026-07-20-45-8261-AM.png?width=670&height=346&name=image-png-Sep-24-2026-07-20-45-8261-AM.png)

Once approved, the yearly variable addition is displayed on the active salary. Here, you can view both the percentage and the estimated annual value of the addition.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Sep-24-2026-07-21-47-9405-AM.png?width=670&height=345&name=image-png-Sep-24-2026-07-21-47-9405-AM.png)

## Change a yearly variable addition

To edit an existing yearly variable addition, open the relevant salary in the **Compensation** tab and click **Actions - Change yearly variable addition**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Sep-24-2026-07-22-16-3273-AM.png?width=670&height=344&name=image-png-Sep-24-2026-07-22-16-3273-AM.png)

Update the **effective date** or **percentage of salary** as needed, then click **Save**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Sep-24-2026-07-22-55-9160-AM.png?width=670&height=347&name=image-png-Sep-24-2026-07-22-55-9160-AM.png)
