Would you like new employees to be automatically created in Entra ID when they’re added in Hailey? With our integration to Entra ID, this is possible—along with seamless transfer of data like job titles and employee numbers!

<Tip>
  First time activating one of **Hailey's standard integrations**? Start by reading [**THIS**](/haileys-standard-integrations) guide to know what to keep in mind before you get started.
</Tip>

---

## What does the integration do?

At each synchronization, the **included data** will be automatically updated via **API transfer** to Entra ID and assigned the same values as in Hailey, since Hailey is the master.

In summary, the integration can help you with the following:

- Create new users in Entra ID
- Update user information in Entra ID
- Disable users in Entra ID after their last working day (optional)

## How does the integration work?

With the API transfer, a synchronization between Hailey and Entra ID takes place **once an hour based** **on changes.** This means that:

- Included data that does not match between Hailey and Entra ID will be updated every hour with the information available in Hailey.

<Note>
  Hailey's integration with Entra ID is designed for the cloud-based version of Entra ID.
</Note>

## What data is included in the integration?

| **HAILEY** | **Entra ID** |
| --- | --- |
| Company email | User principal name |
| Company email (without @domaine) | Mail nickname (without separation) |
| Company phone | Business phone |
| First name | First name |
| Last name | Last name |
| First name + Last name | Display name |

**Optional data fields:**

| **HAILEY** | **Entra ID** |
| --- | --- |
| Titles | Job title (comma separated) |
| Department | Department |
| Legal entity | Company name |
| Location | Office location |
| Date of joining | Employee hire date |
| Employment number | Employee ID |
| Reports to | Manager |
| Private phone, work phone or custom field | Mobile phone |

## What is required to be included in the integration?

For a user to be included in / created through the integration, the employee must have:

- A company email address that matches your domain

Employees are synchronized between Hailey and Entra ID by matching the company email address in Hailey with the UPN in Entra ID. If no matching UPN exists, Hailey will automatically create a new user in Entra ID.

Employees with the following **employment statuses** are included in the integration:

- Will join
- In service
- Leaving

## How is the integration activated?

To activate the integration, you need to:

- Prepare the integration setup in Entra ID
- Add the integration in Hailey
- Fill in the required data for the integration setup
- Include the integration where applicable
- Save and activate

Follow the instructions below to complete the activation of the integration.

### Step 1 - Preparation

Before activating the integration, the person setting up the integration **must have administrator rights in Entra ID**. As a Hailey admin, you automatically have the required rights to set up the integration.

- If someone else, such as your IT, will be responsible for setting up the integration, you can give them the required rights by following the roles & rights guide [**HERE**](/roles-and-rights). The IT will need View & Edit integrations.

- Go to **Settings - Integrations**.

  Users created through the integration will need to enter the **Default password** the first time they sign in to their Microsoft account.

## Does the integration not apply to the entire company?

There is also an option **scope** the integration!

- The scope of the integration allows you to include only employees with a specific locations and/or legal entity in the integration.
- This is important to do immediately when setting up the integration. The reason it must be configured during the initial setup is to ensure that the correct employees are synchronized from Hailey to Entra ID, as synchronization starts immediately.

If these fields are left empty, all employees who meet the integration requirements will be synchronized.

<Note>
  The image below shows and example that only employees belonging to the selected location specified in the integration setup will be included in the integration with Entra ID.
</Note>

### It is also possible to set up multiple integrations with different/multiple accounts in Entra ID.

- If your company has multiple locations and/or legal entities in Hailey, it may be beneficial to create separate integrations with Entra ID for different/multiple Entra ID accounts.

If you want to set up multiple integrations with different Entra ID accounts, repeat the same process as described above. In other words, navigate to the **User provisioning** section and follow the same steps as when you set up the first integration.

- You can see how many integrations with Entra ID you have activated by navigating to **Settings - Integrations - Added**. Here you can also see the scope of each active integration.

When a new employee starts in your organisation and logs into a system using their Entra account which was created through the Entra integration in Hailey, they need to use the password that you set as **Default password** in the integration set up in Hailey.

After adding the **Default password** and clicking **Sign in**, they will be asked to create their own password on the next page. This will be the password that your new employee will use to log into any system connected to your Entra ID.

## Common questions

**Question 1:** If I make a change in Entra ID, will it also be updated in Hailey?

Hailey is the master system, meaning that for the data included in the integration, Hailey is the primary data source. If a change is made directly in Entra ID to a field that is included in the integration, the value will be reset to the value in Hailey.

**Question 2:** How will users that already exist in our Entra ID be matched and handled when the synchronization is activated? Will duplicate users be created?

The integration identifies employees based on their company email address. If the email address already exists in Entra ID, duplicate users will **not** be created. Instead, the integration will identify and match the existing user profile.

**Question 3:** What happens if I change an employee’s company email address in Hailey - how does that affect the integration?

When you change an employee’s company email address in Hailey, a new profile will be created in Entra ID. This is because the email address is used as the unique identifier when creating the employee account and serves as the link between the two systems.

**Question 4:** Does the integration work with on-premises Active Directory?

Hailey’s integration with Entra ID is designed for cloud-based Entra ID.
