## What is add employment and how does it work?

If an employee receives new employment terms, such as a new employment type, title, or employment scope, you can add a new employment to the employee's profile. This makes it easy to manage changes while preserving historical records.

<Note>
  Do you want to add a new employment for multiple employees at the same time? [**HERE**](/add-new-employments-in-bulk)you can learn more about how to do this.
</Note>

How do you add employments?

To add a new employment to an existing employee:

- Go to the employee's profile.
- Click **Actions - Add employment**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-08-58-03-9501-AM.png?width=670&height=438&name=image-png-Jan-23-2026-08-58-03-9501-AM.png)

You will now be guided through the employment wizard. In the first step you choose whether you want to use an **Employee template** for the employment.

- [**HERE**/employee-templates](/employee-templates)you can read more about how employee templates work.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-08-58-58-6532-AM.png?width=670&height=447&name=image-png-Jan-23-2026-08-58-58-6532-AM.png)

In the next step, you can choose whether or not you want to configure a contract for the new employment. If you choose to configure a contract, you will be able to select a contract template.

- If the template contains **Input fields** or **Attachments**, you can select which ones should be included by marking the relevant sections.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-08-59-34-7627-AM.png?width=670&height=432&name=image-png-Jan-23-2026-08-59-34-7627-AM.png)

Then choose a signing method: **Digital Autograph** or **BankID**.

Next, add any individuals who need to review and sign the contract, and specify the order in which they should do so. This is done by setting up the **Signing steps**.

- If you assign a reviewer, the contract will be sent to the reviewer for approval before it is sent out for signing.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-00-53-6466-AM.png?width=670&height=481&name=image-png-Jan-23-2026-09-00-53-6466-AM.png)

In the next step, you will be asked to enter a **start date** and whether the employment has an end date.

- If the employment has no end date, the checkbox **Does the employment have an end?** does not need to be selected.

Also choose whether the active employment should **End** or **Continue.**

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-01-33-1367-AM.png?width=670&height=464&name=image-png-Jan-23-2026-09-01-33-1367-AM.png)

In the next step, the organizational information from the previous employment will be retrieved. You can adjust this if something needs to be changed for the new employment.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-02-05-7655-AM.png?width=670&height=530&name=image-png-Jan-23-2026-09-02-05-7655-AM.png)

Then fill in the employment terms.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-02-44-6490-AM.png?width=670&height=434&name=image-png-Jan-23-2026-09-02-44-6490-AM.png)

If you have custom employment fields, you will have the option to complete or adjust them.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-03-09-1375-AM.png?width=670&height=458&name=image-png-Jan-23-2026-09-03-09-1375-AM.png)

In the next step, you can configure the **Time & time off** settings linked to the employment.

- If the previous employment had **Time & time off** settings configured, these fields will be pre-populated with the same values.
- If you do not use **Time off** or **Time & Time off** in Hailey, you do not need to enter anything here and can proceed to the next step.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-03-40-4333-AM.png?width=670&height=478&name=image-png-Jan-23-2026-09-03-40-4333-AM.png)

Next, you will choose whether the **salary should be updated** with the new employment.

- If you choose to keep the same salary, you can continue without entering additional details.
- If you choose to update the salary, you can enter a **new amount** and when it should take effect.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-05-06-6203-AM.png?width=670&height=474&name=image-png-Jan-23-2026-09-05-06-6203-AM.png)

Regardless of whether you chose to create a contract, you will in the next step be able to start a workflow.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-05-57-4128-AM.png?width=670&height=430&name=image-png-Jan-23-2026-09-05-57-4128-AM.png)

In the final step, you will get a **summary** of the new employment and can **preview** the contract.

- Click the **arrow** when you are ready to send the contract for review and signing.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-09-06-28-2789-AM.png?width=670&height=489&name=image-png-Jan-23-2026-09-06-28-2789-AM.png)

On the employee card, under **Job - Employments,** you can then **view and expand the various employments registered** for the employee.

Once the contract has been signed by all parties, the document will be available under **Docs**.

![](https://docs.haileyhr.com/hubfs/image-png-Dec-19-2025-01-54-40-0067-PM.png)

## How do you manage overlapping employments?

When you add a new employment that should run in parallel with an existing one, **just follow the same employment wizard described earlier in this guide.**

- To keep both employments active at the same time, **toggle** **off** the option **End existing employments.** This way, the employments will overlap instead of the new one replacing the old one.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Nov-17-2025-09-30-01-2143-AM.png?width=670&height=531&name=image-png-Nov-17-2025-09-30-01-2143-AM.png)

If an employee has multiple active employments, Hailey needs to know which one should be considered **Primary**. The primary employment is used as the default in the system. You can change which employment is used as primary by:

- Going to the employee's profile - Job - Employments
- Click the **pencil icon** to the right of the **Employments** section.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Aug-28-2026-02-30-03-3884-PM.png?width=670&height=277&name=image-png-Aug-28-2026-02-30-03-3884-PM.png)

In the next step, you will be able to edit the order of the employments and choose which employment should be classified as **Primary.**

- The highest-ranked active employment will be considered the primary employment.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Aug-28-2026-02-34-27-7358-PM.png?width=670&height=626&name=image-png-Aug-28-2026-02-34-27-7358-PM.png)

Rights

As an admin in Hailey, you always have the ability to Add employment. If you want someone who is not an admin in the system to have the right to add employment, you can set this up under Roles & rights.

Here you can choose to give the right to:

- **Add a new employment to an existing employee:** Actions - Add employment - Yes
- **Update, edit or delete an employment on an employee profile:** Job - General - View and Edit

</Note>

FAQ

**Question:** I didn't finish setting up the new employment. Can I save it as a draft?

Yes! At any point during the hiring process, you can pause and save your progress as a draft, then resume from where you left off later.

![](https://docs.haileyhr.com/hubfs/image-png-Dec-19-2025-01-56-34-4146-PM.png)

**Question:** When should I add employment, and when should I start a completely new employment process?

Use **Add employment** when an existing employee receives a new employment or changes to their employment terms that should be saved as a new record in the employment history.

You can **Edit employment** when you want to correct or update an existing employment record without creating a new record. In this case, the previous values will be overwritten. Keep in mind that this may affect reports and analyses that rely, at least in part, on employment history.

Use **Initiate hire** when hiring a completely new employee who does not yet have a profile in Hailey. This creates both the employee profile and the employee’s first employment record. You can read more about how to initiate an employment [**HERE**.](/iniate-hire)

**Question:** Which parts of the system are affected by the primary employment when an employee has parallel employments?

The prioritization is important because it affects how the employee is displayed and managed throughout the platform, including:

- Workflows, which manager is involved, and how the employee is included in scoped tasks
- Results in employee surveys
- Data scope
- Analytics
- Employee list
- Results in filtered lists
- Managers roles and rights

**Question:** When will the new employment become visible to others on the employee's profile?

Once the contract has been signed by all parties, the new employment will become visible to users who have permission to view employment records on the employee's profile.

The same applies to employments with a future start date. In such cases, the employment will have the status **Will join**.

Draft employments are only visible to the person who created them. Other users will not be able to view any employment drafts.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Aug-28-2026-03-41-22-1138-PM.png?width=670&height=297&name=image-png-Aug-28-2026-03-41-22-1138-PM.png)

**Question:** I can't select the option to configure a contract when adding an employment. Why?

If you are unable to select the option to configure a contract while adding an employment, it is usually because you do not have the required rights in Hailey.

For example, the contract may contain salary information or other details that you are not authorized to manage. If the contract contains variables related to salary, you must have the right to manage salaries in order to update and send the contract. This is because the employment wizard allows you to update the employee's salary before the contract is sent out.

If you do not have the necessary rights, an error message will be displayed in the Add Employment wizard informing you that you do not have the sufficient rights.

Contact your admin if you need help reviewing or updating your rights.
