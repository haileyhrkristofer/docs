title: "Integration to NAV/Altinn"
---

Through Haileys integration it's possible to sync documents from Altinn directly to Hailey ensuring secure data storage - all in one place.

## 1. What does the integration do?

Using this integration, allows easy access to the required files and data directly in Hailey. Documents uploaded to Altinn, such as sick leave certificates, can be automatically structured, sorted, and stored in Hailey. This allows you to access all documents through the employee’s profile, reducing the time spent working across both systems.

## 2. Before activating the integration

Before activating the integration and to ensure that the documents goes to the right place, you need to create employee folders in Hailey. This will make sure the documents actually go to the correct employees profile, secured in their personal folder. In order to use the integration, you need to have at least one folder set up but if you already have one from before and prefer to create a new one - you can do so by clicking on settings, customisation and employee folders. More information on how you can create your own folders [**HERE**](/employee-folders).

## 3. Activating the integration

When it is time to activate the integration, start by going to **Settings → Integrations** in Hailey. Under the **All** tab, the Altinn box will be displayed. Click on it and activate the integration by selecting **Active**, specifying the date from which documents should be synchronized, and choosing the folder where you want the documents to be stored.

You can select a date in the past or in the future, and it is possible to have multiple integrations active at the same time if you wish to keep the synchronizations separate.

<Warning>
  The organization numbers listed are synchronized with Altinn/NAV. Any changes, such as adding, removing, or editing an organization, must be handled by Hailey’s legal department. Contact your Customer Success Specialist when setting up a new configuration or if changes are needed.
</Warning>

To grant Hailey access to synchronize documents from Altinn, navigate to each sub-entity and assign the necessary permissions.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Aug-25-2026-12-52-45-0517-PM.png?width=655&height=349&name=image-png-Aug-25-2026-12-52-45-0517-PM.png)

Navigate to **Meny**. Then go to **Tilgangsstyring**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jun-04-2026-12-23-38-7554-PM.png?width=657&height=412&name=image-png-Jun-04-2026-12-23-38-7554-PM.png)

Click **Systemtilganger** and then **Lag ny systemtilgang**.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jun-04-2026-12-26-34-0522-PM.png?width=670&height=359&name=image-png-Jun-04-2026-12-26-34-0522-PM.png)

Search for **Hailey HR NUF** and proceed.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jun-04-2026-12-28-21-9135-PM.png?width=670&height=327&name=image-png-Jun-04-2026-12-28-21-9135-PM.png)

Click **Opprett** **systemtilgang** to give Hailey access to retrieve the sick leave notifications from Altinn.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jun-04-2026-12-30-20-6820-PM.png?width=670&height=312&name=image-png-Jun-04-2026-12-30-20-6820-PM.png)

It is now time to contact your Customer Success Specialist and inform them which sub-units you want to include in the synchronization. Once you have provided the organization numbers for the sub-units, Hailey’s legal department will set up the units before they become visible in your account.

Please note that this may take up to 48 hours. To read more about underenheter/sub-units, click [**HERE**.](https://www.brreg.no/bedrift/underenhet/)

<Note>
  If you have multiple integrations active, it is recommended to include the configuration ID already when you inform your Customer Success Specialist of the sub-unit’s organization number. This way, Hailey can link the correct sub-unit to the correct configuration ID from the start.
</Note>

Once the activation in Hailey is saved, you can find the integration under **Settings → Integrations → Added**. From here, you can click on the integration to find the configuration ID. You can also deactivate the integration if desired, see the date from which the synchronization applies, and which employee folder has been selected for the documents to be synchronized from Altinn to Hailey.

When the synchronization is ready, the sub-units will appear when you open the active integration in Hailey. The included sub-units will then be visible, and you are now ready to retrieve sick leave notifications into Hailey. From this point on, the sick leave notifications will automatically be placed in the employee’s folder.

## 4. Troubleshooting

If something goes wrong with the integration, there are a few points that can be double-checked:

- Make sure that the employee has the correct personal identification number in Hailey.
- Verify that the sub-unit’s organization number is correct.
- Check that the employee folder included in the synchronization does not have a scope that excludes the employee.
- Ensure that you have permission to view the contents of the folder. This is configured directly in the employee folder under **Settings → Customization → Employee folders**.
