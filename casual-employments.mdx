## What is a casual employment in Hailey?

Casual employment is a way to make employees available for work as needed. In Hailey, a **casual employment** serves as a framework for a defined period. Whenever the employee is needed to work, you can easily create and sign a new employment period within the predefined casual employment period.

<Note>
  Casual employment is not enabled in your Hailey account by default. If you would like to start using this functionality, please contact Customer Success.
</Note>

## Before you get started

Before you can start using casual employment, a few features need to be set up in Hailey. We recommend reviewing the following features and following the instructions in each guide:

- **Contract templates:** Read more [HERE](/create-contract-templates)
- **Employee folders:** Read more [HERE](/employee-folders)
- **Hiring templates:** Read more [HERE](/hiring-templates)
- **Employee templates (optional):** Read more [HERE](/employee-templates)

The standard fields **Contracted scope (%)** and **Contracted hours** are optional fields that can be displayed in the employment period for a **casual employment**. To make these fields available, you need to enable them as standard fields in Hailey.

- [**HERE**](/standard-fields) you can find instructions on how to enable standard fields in Hailey.

## How do you initiate a new casual employment?

The first step in the process when initiating a hiring process in Hailey is to enter the candidate’s basic information and organizational settings. The candidate will then provide the information required to create the contract, using an employment template. After the hiring process is done, its time to send out the signing for the contracted period.

### Step 1 - Initiate hire

<Steps>
  <Step title="Go to the Employees tab from the main menu">
    Go to the **Employees** tab from the main menu
  </Step>
  <Step title="Click Add employee">
    Click **Add employee**
  </Step>
  <Step title="Select Initiate hire">
    Select **Initiate hire**
  </Step>
</Steps>

or,

<Steps>
  <Step title="Go to your homepage">
    Go to your homepage.
  </Step>
  <Step title="Click Initiate hire">
    Click **Initiate hire**
  </Step>
</Steps>

Select **Casual** to continue. Once you have completed the steps above, a setup wizard will open.

You will now be guided through the hiring wizard. In the first step, choose whether you want to create the casual employment using an **Employee template** or continue without one.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-10-28-45-5036-AM.png?width=670&height=427&name=image-png-Jan-23-2026-10-28-45-5036-AM.png)

If you have created **Hiring templates** in Hailey, you will be prompted to choose which template you want to use.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-10-32-54-5948-AM.png?width=670&height=448&name=image-png-Jan-23-2026-10-32-54-5948-AM.png)

Next, enter the candidate's basic information and define the timeframe for the casual employment.

If you want to sign the candidate using **BankID**, the **Do you need the personal identification?** option must be enabled in this step.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-10-33-54-5080-AM.png?width=670&height=469&name=image-png-Jan-23-2026-10-33-54-5080-AM.png)

Provide information about where your new employee will be working, based on the organizational entities available in your account.

<Note>
  An employee can have an **unlimited number of casual employments!** The casual employments can also be combined with regular employments.

  If the employee should be available for work in, for example, different departments or at different locations, you can create a casual employment for each organizational affiliation. This can be done as soon as the employment is finalized.
</Note>

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-10-34-36-6082-AM.png?width=670&height=593&name=image-png-Jan-23-2026-10-34-36-6082-AM.png)

Fill in any custom employment fields that are relevant. Otherwise, you can leave these fields blank. Once you have completed all the required information, click the turquoise **Arrow**.

- After you click the turquoise **arrow**, the employee's profile will be created in Hailey, and an email will be sent to the candidate informing them that you have requested their information in order to finalize the contract.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-10-37-11-1651-AM.png?width=670&height=456&name=image-png-Jan-23-2026-10-37-11-1651-AM.png)

### Step 2 - Gather information from the candidate

In the email, the candidate is asked to provide their personal information and consent to you using that information to generate the contract.

  Would you like to see what the **Candidate Portal** looks like from the candidate's perspective? Watch the video at the top of this guide or click [**HERE**](/hiring-templates).
</Note>

### Step 3 - Finalize hiring

Once this information has been provided, the employment process will move on to the next step: **finalizing the hiring**!

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-12-28-02-4631-PM.png?width=670&height=107&name=image-png-Jan-23-2026-12-28-02-4631-PM.png)

It is now time to set up the **new employee's salary.**

- For casual employment, we have set the payment period to be limited to **Hourly.** Therefore, you only need to make selections regarding the Salary name, [Salary type](/salary-types), and Amount.
- The salary will automatically have the same effective dates as the casual employment you just created for the new employee, so you do not need to specify any dates for the pay.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-12-29-58-6606-PM.png?width=670&height=430&name=image-png-Jan-23-2026-12-29-58-6606-PM.png)

You will then see a **Summary** of the selections you made throughout the hiring process.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-12-30-54-4058-PM.png?width=670&height=590&name=image-png-Jan-23-2026-12-30-54-4058-PM.png)

In the final step of the wizard, you will have the opportunity to **start a workflow** and send your new employee a link to the **preboarding portal.**

Once you have made your selections, click the turquoise **Checkmark** to continue.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-12-32-37-1195-PM.png?width=670&height=425&name=image-png-Jan-23-2026-12-32-37-1195-PM.png)

The new employee's profile has now been created in Hailey, and all the information entered during the hiring process has been saved to their profile.

- You can find the **casual employment** framework on the employee's profile under the **Job** tab, and the salary you created under the **Compensation** tab.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-03-2026-08-07-30-7256-AM.png?width=670&height=413&name=image-png-Jul-03-2026-08-07-30-7256-AM.png)

<Note>
  Would you like to track the hiring process? If so, you can follow its progress in **HR Hub - Hirings**, provided you have right to access that tab.
</Note>

## How do you Add Contracted Periods for casual employees?

Once you have finalized the new employee's casual employment, you can sign contracted periods. **Three additional requirements must be met** for the signing to be possible:

<Steps>
  <Step title="The contracted period you are signing must fall within the d">
    The contracted period you are signing must fall within the dates of the causal employment.
  </Step>
  <Step title="You must have a contract that is used for employment periods">
    You must have a contract that is used for employment periods.
  </Step>
  <Step title="The employee must have a hourly salary">
    The employee must have a hourly salary.
  </Step>
</Steps>

If all the above criteria are met, click on the casual employment you wish to create a contract for. Then click on Add contracted period to get started.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-03-2026-08-23-04-9668-AM.png?width=670&height=434&name=image-png-Jul-03-2026-08-23-04-9668-AM.png)

A wizard will now open to guide you through the entire process.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-01-04-15-8229-PM.png?width=670&height=429&name=image-png-Jan-23-2026-01-04-15-8229-PM.png)

The first step allows you to set the dates during which the current employment period will run. Here, you are free to choose how many days the period should cover.

You can also enter **Contracted hours** and **Contracted** **scope** for the employment period under the **Work terms** section (provided that the standard fields for these have been enabled). Missing these fields?

- You can find instructions on how to enable standard fields in Hailey [**HERE**](/standard-fields).

<Note>
  Only dates that fall within the employment’s start and end dates will be available for selection when creating employment periods at a later stage.
</Note>

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-03-2026-11-07-03-9292-AM.png?width=670&height=430&name=image-png-Jul-03-2026-11-07-03-9292-AM.png)

Then select whether the employment is a **General employment** or a **Temporary substitute**. If it is a Temporary substitute, you must specify who the employee is substituting for and the reason for the substitution.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-03-2026-11-23-45-2928-AM.png?width=670&height=427&name=image-png-Jul-03-2026-11-23-45-2928-AM.png)

The next step is to select which salary applies for the employment period. If the employee has only one salary, no selection is needed, and Hailey will automatically choose the existing one.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-01-07-25-0683-PM.png?width=670&height=430&name=image-png-Jan-23-2026-01-07-25-0683-PM.png)

Once the salary has been selected, we move on to choosing which **contract template** to use.

Does your contract include optional sections and/or input fields? Then select the sections you want to include to continue.

<Note>
  The contract templates available at this step have **Contracted period** selected on the contract templet.
</Note>

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-01-08-16-8483-PM.png?width=670&height=430&name=image-png-Jan-23-2026-01-08-16-8483-PM.png)

Choose your signing method: **Digital autograph** or **BankID**.

In this step, you can also select who will review and sign the contract, and in which order by setting up your signing steps.

- If you select a reviewer, the contract will be sent to the reviewer for approval before it is sent out for signature.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jan-23-2026-01-12-10-7664-PM.png?width=670&height=462&name=image-png-Jan-23-2026-01-12-10-7664-PM.png)

Finally, you will see a summary of the choices you have made, along with the option to preview the contract. Ready to send the contract? Then click the on the **Airplane**!

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-06-2026-12-51-48-5470-PM.png?width=670&height=540&name=image-png-Jul-06-2026-12-51-48-5470-PM.png)

The employment period will be visible under the Casual employment - **Contracted periods** for the employee.

Once the contract has been reviewed and signed by all parties, it will be available in the employee's **Dos** tab.

![](https://docs.haileyhr.com/hs-fs/hubfs/image-png-Jul-06-2026-12-57-47-4029-PM.png?width=670&height=548&name=image-png-Jul-06-2026-12-57-47-4029-PM.png)

## Key terms

- **Casual employment:** also referred to as framework employment, hourly employment, or intermittent employment.
- **Contracted period:** The contracted period of employment for a casual employee.

## Rights

As an admin in Hailey, you always have the right to initiate and add a **casual employment**. If you want someone else, such as a manager, to be able to do this, you can give them the appropriate rights based on their responsibilities.

<Note>
  You can read more about Roles & rights **[HERE](/roles-and-rights).**
</Note>

**Initiate a Casual Employment**

To initiate a new casual employment (i.e., to start a hiring process for a brand-new casual employee) the following right is required: Action - Initiate casual employment hire.

To initiate a casual employment using employee templates (i.e., creating an employment based on predefined values), the following right is required: Action - Initiate casual employment hire with employee template.

**Add a Casual Employment**

The right to Add Casual Employment (meaning to manually add a casual employment to an employee profile) is found under: Action - Add casual employment

In addition, the right to View & Edit a Casual Employment is required. This allows users to view and edit existing casual employments.

**Company signatory**

The ability to act as the company signatory is a right that must be configured for both admins and any other employees who should be able to sign on behalf of the company. You can find this under: Other rights - Can be company signing party.

    - Go to the employee's profile.
    - Click **Action - Cancel hiring process**.

    Once the hiring process has been cancelled, the **Being hired** status will be removed. The employee will instead receive another employment status, such as Will join, In service, Leaving, or Garden leave. Which status is displayed depends on the start and end dates registered on the employee's employment.

    - Select **Delete**.
